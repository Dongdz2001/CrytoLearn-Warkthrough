# 🔐 CryptoLearn

Ứng dụng React tĩnh (Vite) cung cấp lộ trình học tập mật mã học toàn diện, từ lý thuyết cơ bản đến các công cụ thực hành và trò chơi tương tác.

## 🚀 Tính năng chính

- **Lý thuyết chi tiết**: Giải thích lịch sử, nguyên lý hoạt động và độ an toàn của hơn 10 thuật toán mật mã.
- **Demo Tool**: Công cụ mã hóa/giải mã trực quan cho từng thuật toán (Caesar, Vigenère, AES, RSA, Hash, ...).
- **Trò chơi đoán thuật toán**: Thử thách bản thân bằng cách nhận diện thuật toán qua bản mã (ciphertext) với hệ thống gợi ý và tính điểm.
- **Giao diện hiện đại**: Hỗ trợ Dark Mode, thiết kế Glassmorphism và hiệu ứng chuyển động mượt mà.

## 📁 Phân loại thuật toán

1. **Mã hóa 2 chiều**
   - Cổ điển: Caesar, Vigenère, Atbash, ROT13
   - Đối xứng (Symmetric): XOR, AES, DES, 3DES
   - Bất đối xứng (Asymmetric): RSA
2. **Mã hóa 1 chiều (Hashing)**
   - MD5, SHA-1, SHA-256, SHA-512
3. **Chữ ký số (Digital Signature)**
   - RSA Signature
4. **Bảng mã (Encoding)**
   - Base64, Hex, Binary

## 🛠️ Cài đặt và Chạy thử

```bash
# Clone repository
git clone https://github.com/Dongdz2001/CrytoLearn-Warkthrough.git

# Di chuyển vào thư mục
cd CrytoLearn-Warkthrough

# Cài đặt dependency
npm install

# Chạy project ở chế độ development
npm run dev
```

## 🏗️ Công nghệ sử dụng

- **Vite + React**: Nền tảng xây dựng ứng dụng nhanh và linh hoạt.
- **React Router**: Điều hướng client-side mượt mà.
- **Crypto-JS**: Thư viện mã hóa cho AES, Hash, DES.
- **Node-Forge**: Xử lý mã hóa bất đối xứng RSA và chữ ký số.
